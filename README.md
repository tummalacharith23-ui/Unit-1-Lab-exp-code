Website Projects
This repository contains simple HTML/CSS website projects demonstrated in the screenshots.
Projects
1. ShopEasy — Online Shopping Website
- Displays product cards with images, prices, and ratings.
- Includes a promotional banner advertising a 50% sale.
- Provides navigation links and Add to Cart buttons.
- Shows a cart item count.
2. ElectroStore — Electronics Store
- Displays electronics products such as smartphones and smartwatches.
- Shows product names, prices, and Add to Cart buttons.
- Includes a cart counter and contact information.
3. Daily News — Online News Portal
- Organizes news into National, Sports, and Technology sections.
- Includes Read More buttons for each news category.
- Provides navigation links and a contact email.
Technologies
- HTML
- CSS
- JavaScript (if used for interactive features)
Getting Started
1. Download or clone this project.
2. Open the project folder.
3. Open the relevant .html file in your web browser.
Example filenames shown in the screenshots:
- web1.html — Online Shopping Website
- web2.html — Electronics Store Website
- web3.html — Online News Portal
Notes
- These are front-end demonstration websites.
- Product details and contact email addresses are sample content.
- A working cart, live news feed, or checkout system requires additional implementation if not already included.
